# 短剧AI智能助手项目 README

# 项目介绍

本项目是一款基于 FastAPI \+ Agent \+ RAG \+ 向量库（Milvus）开发的短剧AI智能助手，旨在为用户提供一站式短剧创作服务。支持剧本生成、分镜脚本制作、剧本改写/续写/扩写/精简、元信息提取，同时支持多格式文件上传解析、相似剧本仿写，具备完整的ReAct智能思考链路，可在前端展示AI的思考过程，全程基于用户历史对话和向量库内容生成，杜绝凭空编造剧情。

项目核心定位：轻量化、高可用、易扩展的短剧创作辅助工具，适配个人创作者、短剧团队的快速创作需求，支持本地化部署和功能定制。

# 核心功能

## 一、基础短剧创作功能

- **剧本生成**：支持按主题、风格、时长、关键词，生成符合要求的短剧剧本（默认支持爽文、校园、古风、悬疑等多种风格）。

- **分镜脚本生成**：基于已有剧本，自动转换为可直接拍摄的分镜脚本，包含场景、地点、人物、画面、台词等核心要素。

- **剧本编辑**：支持剧本改写、续写、扩写、精简，严格基于用户提供的剧本或历史对话内容，不偏离原有风格和剧情。

- **元信息提取**：自动提取剧本的标题、关键词、角色信息，并对剧本质量进行评分，辅助用户优化内容。

## 二、RAG检索与相似创作功能

- **多格式文件上传**：支持 PDF、DOCX（Word）、TXT 格式文件上传，自动解析文本内容并分块存入Milvus向量库。

- **相似剧本仿写**：用户上传剧本或发送已有剧本后，可生成风格、结构、节奏、人物关系相似但不抄袭的新剧本，基于向量库检索实现精准匹配。

- **智能检索**：支持检索历史剧本、上传文档，为剧本创作提供参考，保持创作风格统一。

## 三、智能体与记忆功能

- **Agent意图识别**：智能识别用户需求（生成、分镜、改写、仿写等），自动调用对应工具，无需手动触发。

- **双重记忆管理**：Redis 存储短期聊天历史，保证对话连贯性；Milvus 存储长期剧本资产，支持持久化检索和复用。

- **ReAct思考链路**：AI智能体的完整思考过程（意图识别→上下文获取→工具调用→结果生成）可结构化返回，支持前端展示，让AI的决策过程可追溯。

## 四、接口与兼容性

- 提供 RESTful API 接口，支持剧本生成、文件上传、对话交互等所有功能。

- 支持流式输出（stream）和普通返回两种模式，适配前端不同展示需求。

- 代码结构清晰，支持功能扩展，可快速新增剧本风格、工具类型。

# 快速开始

## 一、环境准备

1. 安装 Python 3\.9\+

2. 安装依赖包：`pip install \-r requirements\.txt`

3. 启动 Milvus 向量库（本地部署或使用云服务），配置对应连接参数（见 config\.py）

4. 启动 Redis 服务，配置连接参数（见 config\.py）

## 二、项目启动

```bash
# 开发环境启动
uvicorn main:app --reload

# 生产环境启动（建议使用gunicorn）
gunicorn main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
```

## 三、接口测试

项目启动后，访问 `http://127\.0\.0\.1:8000/docs` 即可看到自动生成的接口文档，可直接在页面上测试所有功能：

- /chat/message：普通对话接口（支持所有创作功能）

- /chat/stream：流式对话接口

- /script/generate：剧本生成接口

- /script/upload：文件上传接口

## 四、基础使用示例

1. 生成剧本：调用 /script/generate，传入主题、风格、时长等参数，生成剧本并自动存入向量库。

2. 生成分镜：在对话中发送“根据上面的剧本生成分镜脚本”，AI自动识别意图并生成分镜。

3. 上传文件仿写：上传PDF剧本，发送“根据这个文档生成相似的剧本”，AI检索文件内容并生成仿写剧本。

# 核心架构说明

## 整体架构流程

用户请求 → FastAPI接口 → Agent智能体（意图识别） → 上下文获取（Redis历史 \+ Milvus检索） → 工具调用 → 结果生成 \+ 思考链路返回 → 存储记忆（Redis \+ Milvus） → 前端展示

## 核心模块说明

1. **Agent模块（services/agent\.py）**：核心智能体，负责意图识别（生成、分镜、改写、仿写等）、ReAct思考链路管理、工具调用调度，统一上下文获取逻辑。

2. **LLM模块（services/llm\.py）**：大模型集成模块，封装剧本生成、分镜转换、仿写等核心方法，包含严格的提示词约束，避免剧情跑偏。

3. **RAG模块（services/rag\.py）**：向量库交互模块，负责文件解析、文本分块、Milvus入库与检索，为仿写、参考功能提供支撑。

4. **记忆模块（services/memory\.py）**：Redis交互模块，负责聊天历史的存储与读取，保证对话连贯性。

5. **接口模块（routers\.py）**：封装所有API接口，包含聊天、剧本生成、文件上传等，支持流式输出。

# 注意事项

- 确保 Milvus 和 Redis 服务正常启动，配置参数与 config\.py 一致，否则会导致记忆存储、检索失败。

- 文件上传时，建议上传纯文本剧本（PDF/DOCX需确保无复杂格式，避免解析失败）。

- 仿写剧本时，确保已上传参考文档或生成过历史剧本，否则AI会基于默认风格生成，无法实现相似效果。

- 修改代码时，请勿删除原有核心逻辑，新增功能建议做增量开发，避免影响现有功能正常运行。

# 功能扩展建议

- 新增剧本风格：在 agent\.py 的 STYLE\_KEYWORDS 中添加新风格，同步优化 llm\.py 提示词。

- 新增工具类型：在 agent\.py 中新增意图识别分支，在 llm\.py 中封装对应方法，即可扩展新功能（如剧本配音文案生成）。

- 优化前端展示：基于返回的 ReAct 思考链路，可在前端做动态展示，提升用户体验。

- 增加权限管理：新增用户认证模块，实现不同用户的剧本资产隔离。
